# Информационная система "Старостат" | ERP "Group University Manager"

Приложение для автоматизации контроля и учёта студентов. Разработано с учётом специфики [ФГБОУ ВО "МГТУ им. Г.И. Носова"](https://magtu.ru).

------------
# Возможности программы

- Учёт студентов, их актуальных контактов и данных, статуте обучения
- Учёт посещаемости студентов на парах
- Учёт отсутствия по болезни, учёт справок (требование прямо прописано в Рабочей инструкции "Организация работы старосты учебной группы" - СМК-О-РИ-3/4-9-23, п. 3.2)
- Организация учёта распределения группы по нескольким типам подгрупп в случае разного разделения на дисциплинах
- Просмотр расписания с учётом выходных и праздников

--------------------
# Инструкция по настройке и запуску

1. Переименуйте `config-example.yml` в `config.yml`
2. В файле укажите:
	1. `cipher` - шифр направления (например, 11.03.04)
	2. `name` - наименование направления (например, Электроника и наноэлектроника)
	3. `speciality` - наименование специальности, как указано в учебной программе (например, "Интернет вещей в промышленной электронике")
	4. `departament` - выпускающая кафедра (например, "Кафедра электроники и наноэлектроники")
	5. `full_name` - полное наименование учебного заведения
	6. `institute` - полное наименование института в составе университета
	7. `last_name` - официальная аббревиатура учебного заведения
	8. `status` - "Федеральное государственное **бюджетное/автономное (выберите необходимое)** образовательное учреждение высшего образования"
	9. `user` - ваше ФИО
3. Запустите:
для Linux:
```
python3 main.py
```
для Windows:
```
python main.py
```

либо скомпилируйте через Nuitka, установив библиотеку `pyqt6` и выполнив команду
```
python -m nuitka --mode=onefile --enable-plugin=pyqt6 --include-qt-plugins=sensible --include-data-dir=assets=assets --output-dir=build --output-filename=starostat main.py
```
